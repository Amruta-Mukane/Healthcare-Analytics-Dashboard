# Healthcare Analytics Dashboard

## Project Overview

An interactive Power BI dashboard designed to analyze child care, custody, transfer, discharge, and reunification-related data.

## Tools & Technologies

- Power BI
- Data Visualization
- Data Analysis

## Dashboard Features

- KPI cards for key performance indicators
- Annual discharge outcomes
- HHS care analysis by year
- Monthly stage distribution
- HHS transition rate
- CBP custody trend
- Stage distribution analysis
- CBP custody details
- Interactive month filter

## Key Insights

- Analyzed children across different care stages.
- Compared HHS care across different years.
- Analyzed annual discharge outcomes.
- Tracked CBP custody trends.
- Examined the distribution of children across different stages.
- Added interactive filtering for monthly analysis.
